**NVIDIA 掌舵人 Jensen Huang 宣布辞职，科技界震动**

Anthropic 详细公布了其 Managed Agents 托管服务的技术架构，提出了“将大脑（Claude 及 harness）与双手（工具沙盒）及会话日志彻底解耦”的设计哲学。这一演进解决了长上下文 Agent 在容器崩溃、权限越界和状态丢失上的传统痛点，将容器与 harness“牲口化（Cattle）”而非“宠物化（Pet）”，为行业构建长周期运行、安全隔离的 AI Agent 基础设施提供了范本。

**Cursor 供应链安全危机：恶意插件入驻 VS Code 市场并植入后门**

### Anthropic Engineering Blog

**Building strong safety evaluations**
• **核心论点**：系统性探讨构建高质量 AI safety 评测（evals）的核心原则与避坑指南。
• **关键要点**：
  * Safety evals 旨在衡量模型引发或加剧伤害的倾向，而非具体的业务能力。
  * 评测团队需要方法论专家与领域专家（心理学、生物学、政治学）共同构建，缺一不可。
  * 在安全测试时通常需关闭默认防护机制，因此必须在无网络访问的沙盒环境中运行并实时监控。
  * 区分观察性设计（比较不同模型得分）与因果设计（控制单一变量验证特定干预效果）。
  * 警惕构建有效性（construct validity）失真，例如在自残场景中纯粹的拒绝（refusal）并非最佳回应，共情与资源引导才是“适当响应”。
  * 提出了针对多轮对话的“适当响应率”评测，单轮表现不佳即判整个对话不合格。
  * 双重用途领域（如生物学、网络安全）中，最佳表现是回答合法请求的同时扣留具备可操作性的有害细节。
  * 单轮评测必须将有害请求（测试拒答率）与平民无害请求（测试过度拒绝率）成对测试。
• **值不值得深读**：非常值得，对从事 LLM 评测与安全对齐的工程师有极高的实操指导价值。

**Scaling Managed Agents: Decoupling the brain from the hands**
• **核心论点**：Anthropic 介绍其 Managed Agents 托管服务如何通过解耦大脑、双手与会话日志，打造长周期 Agent 架构。
• **关键要点**：
  * 类比操作系统将硬件虚拟化为进程和文件，托管 Agent 将 session、harness 与 sandbox 抽象化。
  * 废弃了将所有组件打包在单一容器的旧设计，避免容器变成需要人工维护的“宠物（Pet）”。
  * 将大脑（Claude + harness）与双手（工具/沙盒）分离，双手执行失败时可以像常规工具错误一样重新初始化。
  * 会话日志独立于 harness 存储，使 harness 具备无状态崩溃恢复能力（可通过 `wake(sessionId)` 启动新 harness 重建状态）。
  * 凭证安全隔离：生成的代码运行在沙盒内，而 GitHub 令牌或 OAuth 密钥保存在沙盒外的凭证库中，彻底阻断 Prompt 注入攻击。
  * 会话日志充当上下文窗口之外的持久化对象，harness 可灵活切片与检索历史事件流，避免不可逆压缩造成的信息遗失。
• **值不值得深读**：非常值得，架构设计思想对生产级 Agent 系统建设极具启发。
