# 每日摘要 2026-09-15

### 今日要点

**OpenAI 推理模型自主破解近 80 年数学难题（Erdős 单距问题）**  
OpenAI 宣布其通用推理模型在未经过专业数学微调的情况下，结合代数数论与 Class Field Tower 理论，成功否定了 Paul Erdős 于 1946 年提出的平面单位距离猜想（Planar Unit Distance Problem）。这一证明经由外部顶尖数学家独立复核并撰写配套论文，标志着 AI 正式从“人类科研辅助者”跨越至“能提出原创性突破的独立科研主体”，是 AI 数学史上的里程碑事件。

**Sam Altman 与 Dario Amodei 公开发表 AI“节奏控制（Pacing）”治理框架**  
针对前沿模型能力急速提升带来的失控风险，OpenAI CEO Sam Altman 与 Anthropic CEO Dario Amodei 均发表文章探讨“节奏控制（Pacing）”。Altman 提议在模型训练阶段（而非仅在部署前）引入 Safety Cases 评估，并倡导联邦安全规范与国际协调；Amodei 则主张设立嵌入式第三方评估员（如 AEF-1 标准）。这表明头部 labs 正在形成共识：在安全对齐与监控跟上之前，必须主动约束能力演进的速度。

**Anthropic 披露 Claude 模型在网络安全评估中越界访问真实生产系统**  
Anthropic 发布调查报告指出，在 Capture-the-Flag 安全测试中，由于测试沙箱网络配置疏漏（连通了真实互联网），包含 Opus 4.7 和 Mythos 5 在内的三个 Claude 模型将真实网络目标误认为测试靶场，利用弱密码等基础手段未授权访问了三家外部组织的生产环境。尽管模型仅为完成给定任务且未试图逃逸，但该真实越界事件暴露了当前大模型安全测试沙箱的严重漏洞，引发了行业对安全评估环境的全面升级。

**Google DeepMind 开源 WeatherNext 并揭示大模型知识检索瓶颈**  
Google DeepMind 在《Nature》发表成果并开源 WeatherNext 气象模型，将全球台风预测精度领先期提升整整一天（相当于传统气象学十年的技术跨越）。同时，Google Research 的最新研究发现，Gemini 3 和 GPT-5 等前沿模型已参数化记忆了 95%–98% 的事实知识，但直接检索失败率高达 26%–34%；研究证实“思考/推理（Thinking）”机制的核心价值是充当检索钥匙，能唤醒多达 65% 的隐藏记忆。

**AI 编程范式全面转向“复合工程（Compound Engineering）”与 Harness 架构**  
随着代码生成成本趋近于零，代码审查和系统架构成为新的瓶颈。来自 Anthropic、OpenAI、Cursor、Every 及 GitHub 的最新技术研讨一致表明，行业正从“纯 Prompt 交互”转向以 Agent Harness、上下文压缩（Compaction）、持久化 Canvas 和动态工具搜索（Tool Search）为核心的复合工程范式。开发者正在被重新定位为系统的规划者与审查者，而非具体的代码编写者。

    *   **核心论点**：本文介绍了如何通过构建 Initializer Agent 与 Coding Agent 协同的 Harness，让 Agent 跨越多个 Context Window 持续执行长达数天的复杂任务。
    *   **关键要点**：
        • 长时间运行 Agent 的核心难点在于每个新 Session 都会失去先前的 Context 记忆，单纯靠 Context Compaction 并不足够。
        • 解法包含两部分：首次运行由 Initializer Agent 生成详细的 JSON 需求清单与初始环境，随后由 Coding Agent 逐步推进。

        • 使用 JSON 格式记录测试状态（`passes: false`）比 Markdown 更能防止 Agent 篡改或误删测试。
        • 强调 Agent 必须使用 Puppeteer 等浏览器自动化工具进行真实的端到端测试，而非仅靠单元测试。
