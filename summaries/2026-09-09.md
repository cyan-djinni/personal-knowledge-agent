### Anthropic Engineering Blog

#### Effective context engineering for AI agents
• **核心论点**：构建高效 AI Agent 的重点正从 Prompt engineering 转向 Context engineering，即如何在有限的注意力预算内优化 Token 的配置与维护。
• **关键要点**：
  • Context engineering 是指在模型推理过程中精选和维护最佳 Token 集合的策略，包括系统指令、工具、MCP、外部数据和消息历史等。
  • 提出了“Context rot（上下文腐烂）”概念：随着上下文窗口 Token 增加，模型准确检索信息的能力会下降，注意力预算会被稀释。
  • System prompts 应保持在“Goldilocks zone（适中区）”：既不过度硬编码脆弱逻辑，也不提供过于模糊的高层指导。
  • 工具设计应遵循 Token 高效原则，避免功能重叠和工具库膨胀，确保人类和 Agent 都能清晰判断工具的使用场景。
  • 详细介绍了管理长流程 Agent 上下文状态的循环精炼技巧。
• **值不值得深读**：极其推荐，是当前构建长流程 Agent 系统必读的技术指南。
• 原文链接：https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents

#### A postmortem of three recent issues
• **核心论点**：Anthropic 详细复盘了近期导致 Claude 回答质量偶发性下降的三起底层基础设施 Bug，并分享了修复与改进措施。
• **关键要点**：
  • 澄清官方绝不会因服务器负载、时间或需求增加而故意降低模型质量，问题完全由 Bug 引起。
  • Bug 1（路由错误）：短上下文请求被误路由到 1M 长上下文服务器，在高峰期影响了 16% 的 Sonnet 4 请求及 30% 的 Claude Code 用户。
  • Bug 2（TPU 配置错误）：导致生成 Token 时出现随机字符（如在英文回答中夹杂泰文或语法错误），影响了 Opus 4.1、Opus 4 和 Sonnet 4。
  • Bug 3（XLA 编译器 Bug）：在优化采样代码后触发了 XLA 编译器的混合精度计算 Bug，导致高概率 Token 偶尔丢失，影响了 Haiku 3.5 等模型。
  • 目前所有修复已全部上线，并增加了针对非预期字符和编译器的自动化部署检测。
• **值不值得深读**：对大模型推理架构、跨硬件平台部署和故障排查感兴趣的工程师非常值得一读。
• 原文链接：https://www.anthropic.com/engineering/a-postmortem-of-three-recent-issues

#### Writing effective tools for agents — with agents
• **核心论点**：为 AI Agent 编写工具需要转变思维，将其视为非确定性 Agent 与确定性系统之间的契约，并推荐与 Agent 协作来迭代改进工具。
• **关键要点**：
  • 工具的“人体工程学（Ergonomics）”至关重要，适合 Agent 使用的工具往往对人类来说也直观易懂。
  • 建议先快速构建工具原型，并使用 Claude Code 等工具本地连接 MCP 服务器进行测试。
  • 建立基于真实业务场景的评估集（Eval），避免过于简单的沙盒环境，每个评估任务需具备可验证的结果。
  • 在系统提示中加入推理与反馈块（Chain-of-thought），或者开启 Interleaved thinking，用来探究 Agent 的决策过程。
  • 分析工具调用的耗时、错误率和冗余调用，通过改进描述或整合参数来消除盲区。
• **值不值得深读**：非常实用，适合所有基于 MCP 或自定义工具开发 Agent 的应用开发者。
• 原文链接：https://www.anthropic.com/engineering/writing-tools-for-agents

#### Why we no longer evaluate SWE-bench Verified
• **核心论点**：OpenAI 宣布停止使用 SWE-bench Verified 作为前沿模型代码能力的评估标准，指出该基准测试存在严重的数据污染和测试用例缺陷。
• **关键要点**：
  • 审视了 o3 未能一致解决的 138 个问题后发现，59.4% 的失败案例源于测试本身存在缺陷（如测试用例过于苛刻、强制特定未声明的函数名，或包含了未在任务描述中提及的功能验证）。
  • 数据污染严重：开源仓库的代码和 Issue 广泛存在于前沿模型的训练集中，模型能直接复现人类编写的“Gold patch”，得分提升不再反映真实的自主编程能力。
  • 在找到更好的无污染评估手段前，OpenAI 建议行业转向使用 SWE-bench Pro 进行评估。
• **值不值得深读**：从事 LLM 评估（Evals）和 AI Coding 研发的团队强烈推荐阅读。

#### What is happening with code reviews?
• **核心论点**：在 AI Agent 导致代码提交量暴增的背景下，总结了各大科技公司与初创企业应对 Code Review 危机与改进流程的五种模式。
• **关键要点**：
  • **模式 1：人类审查 AI 的 Review**（最流行）。引入 CodeRabbit、Greptile 或自研 Agent（如 Uber 的 uReview）先做对抗性审查并过滤噪音，人类只做范围决策。
  • **模式 2：按破坏半径（Blast radius）分流**。低风险代码由 Agent 审查后直接上线，涉及 API/Auth/DB 架构的高风险变更强制人工审查（OpenAI 和 Anthropic 均采用此法）。
  • **模式 3：只审查方案/测试/Schema，不看具体实现**。将精力放在“前置设计”与“后置结果”的把控上。
  • **模式 4：拆分为微型 PR**；**模式 5：坚持完全全手工审查**。
• **值不值得深读**：强烈推荐，对研发团队 Leader 和工程架构师具有极高的实操参考价值。
• 原文链接：https://newsletter.pragmaticengineer.com/p/what-is-happening-with-code-reviews

### Ahead of AI (Sebastian Raschka)

#### Categories of Inference-Time Scaling for Improved LLM Reasoning
• **核心论点**：系统性地梳理与归类了提高 LLM 推理能力的各种推理时扩展（Inference-time scaling）技术框架。
• **关键要点**：
  • 将训练无涉（Training-free）的推理扩展技术划分为六大核心类别：思维链提示（CoT）、自一致性（Self-Consistency）、Best-of-N 采样、带验证器的拒绝采样（Rejection Sampling with Verifier）、自我修正（Self-Refinement）以及解法路径搜索（Search Over Solution Paths）。
  • 阐述了“训练算力”与“推理算力”的双轮驱动关系，在部署模型时增加推理扩展是低成本提升回答准确率的最有效途径。
  • 分享了作者在编写新书章节时的实测数据：合理组合自一致性与自我修正，可将基础模型的准确率从 15% 提升至 52%。
• **值不值得深读**：强烈推荐，大模型应用开发与推理优化从业者不可错过的理论总结。
• 原文链接：https://magazine.sebastianraschka.com/p/categories-of-inference-time-scaling

#### The State Of LLMs 2025: Progress, Problems, and Predictions
• **核心论点**：总结了大语言模型年度技术演进，重点解析了 DeepSeek R1、RLVR 与 GRPO 算法带来的突破，并对未来趋势做出预测。
• **关键要点**：
  • **年度核心**：2025 年是 Reasoning 和 RLVR（带可验证奖励的强化学习）之年，DeepSeek R1 证明了通过 GRPO 算法和极低成本即可训练出顶尖推理模型。
  • **历年焦点演变**：2022（RLHF+PPO）-> 2023（LoRA SFT）-> 2024（Mid-Training/合成数据）-> 2025（RLVR+GRPO）。
  • **未来预测**：2026 年将迎来 RLVR 在数学/代码之外领域的全面泛化及极端推理时扩展；2027 年的重点攻坚方向将是持续学习（Continual Learning）与克服灾难性遗忘。
• **值不值得深读**：强烈推荐，了解 LLM 技术前沿发展脉络与未来趋势的复盘佳作。
• 原文链接：https://magazine.sebastianraschka.com/p/state-of-llms-2025

#### Halley The Superforecaster
• **核心论点**：通过天文学家埃德蒙·哈雷（Edmond Halley）的真实历史案例，探讨启蒙时代早期人们如何在缺乏现代统计学工具的情况下开展预测与科学推演。
• **关键要点**：
  • 哈雷不仅成功预测了哈雷彗星 76 年的回归周期，更开创了现代人口统计学与精算学（Actuarial science）。

### South Park Commons

#### What is -1 to 0?
• **核心论点**：定义了创业中最混乱也最重要的阶段“ -1 到 0 ”——即创业者如何在陷入迷茫时找到值得为之奋斗十年的坚定信念（Conviction）。
• **关键要点**：
  • 如果“ 0 到 1 ”是寻找产品市场契合度（PMF），那么“ -1 到 0 ”就是寻找**创始人市场契合度（Founder-Market Fit）**。
  • 优秀人才往往更容易在此阶段迷失，因为“能力”会增加选择的混沌度。
  • 在 AI 时代，随手构建原型极其容易，低信念的融资反而更容易让人陷入局部最优解（Local maxima）的死胡同。
  • 倡导“Slow to go fast”，把探索想法（Ideation）当成一份严肃的正式工作来做，而非等待凭空的“Eureka”时刻。
• **值不值得深读**：所有正在准备创业、处于迷茫期或寻找方向的开发者必读的经典好文。
• 原文链接：https://blog.southparkcommons.com/p/what-is-minus-1-to-0

#### Trusting Your Agent Is Overrated
• **核心论点**：提出在 AI Agent 时代，建立信任的重心不应仅仅在于增加“信任供给”，而在于努力降低任务场景所要求的“信任需求”。
• **关键要点**：
  • 将传统信任公式扩展为动态比例：$\text{信任行动} = \frac{\text{提供的信任}}{\text{要求的信任}}$。
  • **提供的信任**由声誉/凭证、直接证据与利益对齐决定；**要求的信任**由失败风险（Stakes）与系统不透明度（Opacity）决定。
  • 在 AI 时代，由于假证据容易生成、模型存在幻觉和黑盒特性，“提供的信任”边际效益递减。
  • AI 产品降低门槛的核心杠杆在于分子端的“减负”：提供极佳的撤销（Undo）机制、渐进式权限阶梯、只读/写入权限隔离，以及可追溯可审计的操作日志。
• **值不值得深读**：强烈推荐，所有 Agent 产品经理和架构师必读的商业与交互设计指南。
• 原文链接：https://blog.southparkcommons.com/p/trusting-your-agent-is-overrated

### Paul Graham Essays

#### Superlinear Returns
• **核心论点**：剖析现实世界中表现与回报之间呈现“超线性（Superlinear）”关系的内在逻辑，指出这是由指数增长与门槛效应共同决定的。
• **关键要点**：
  • “付出多少就收获多少”在真实商业和科学界并不成立；胜者往往能获得远超比例的巨大回报（Winner-take-all）。
  • 超线性回报的两大根本成因：**指数增长**（如细菌培养、初创公司复利、知识积累）与**门槛效应**（如比赛胜负、跨越新科学边界）。
  • 知识具有分形特征，一旦推开某一领域的边界门槛，就能获得对该领域所有新发现的优先探索权。
  • 给野心勃勃者的建议：选择具有复利效应的工作，保持终身学习，并学会从失败中汲取复利。
• **值不值得深读**：强烈推荐，创业者与野心家必读的人生认知指南。
• 原文链接：https://paulgraham.com/superlinear.html

#### How to Do Great Work
• **核心论点**：总结跨领域做出伟大工作（Great Work）的通用框架与方法论指南。
• **关键要点**：
  • **四大步骤**：选择一个领域 -> 学习并达到知识前沿 -> 发现前沿的破洞与缝隙 -> 深入探索有潜力的裂缝。
  • 选择工作的三个标准：天分（Aptitude）、深厚兴趣（Interest）以及发挥空间（Scope）。
  • 保持强烈的好奇心与对怪异想法（Outlier ideas）的追求；当你对某些他人觉得无聊或可怕的细节极度着迷时，通常是极佳的信号。
  • 做出伟大成果的最好动力组合：好奇心（Curiosity）、乐趣（Delight）以及做出惊人成就的渴望。
• **值不值得深读**：Paul Graham 的扛鼎长文，强烈推荐反复阅读。
• 原文链接：https://paulgraham.com/greatwork.html

#### How to Get New Ideas
• **核心论点**：阐述获取新灵感的根本方法在于在知识的前沿去发现和观察异常现象（Anomalies）。
• **关键要点**：
  • 知识增长具有分形特征，远看平滑，近看布满罅隙。
  • 获得好灵感的方法就是学会注意到那些看似奇怪、缺失或被破坏的破绽，并深入探索它们。
• **值不值得深读**：短小精悍，极具启发性。
• 原文链接：https://paulgraham.com/getideas.html
