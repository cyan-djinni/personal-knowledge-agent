## 今日要点

**Anthropic 正式发布 Claude Haiku 5.5 并调降 API 整体计费**
Anthropic 推出了速度最快、成本最低的轻量级模型 Claude Haiku 5.5。该模型在小规模任务与子 Agent 协作中表现优异，平均运行成本比前代降低 75%，同时 Sonnet 5.5 的缓存读取价格降幅达 50%。这一降价策略配合为 API 订阅用户按月发放的 Credit，极大地降低了开发者构建高吞吐量 Agentic 应用的边际成本，标志着智能化 Agent 生态正全面向高性价比架构演进。

**Cursor 紧急处理恶意 Claude Code 扩展供应链攻击事件**
Cursor 在其 VS Code Extension Marketplace 中拦截并清理了伪造的 `Anthropic.claude-code` 恶意插件（涉及 2.1.312 与 2.1.313 版本）。攻击者试图通过在 `authorized_keys` 中写入后门 SSH 密钥、启动后台服务及建立反向隧道窃取主机信息。虽然恶意服务器已离线且未影响官方发布，但该事件再次为当前基于 Agent 驱动的开发者工具供应链安全敲响了警钟。

**Anthropic 工程团队深度解构 Managed Agents 架构与 Harness 设计**
Anthropic 连续发布技术长文，展示了其在构建 Managed Agents 和长时间运行 Agent Harness 上的最新范式。工程团队通过将“大脑”（模型与 Harness）与“手”（执行沙盒）以及“会话日志”全面解耦，避免了传统的沙盒崩溃死锁；同时引入“生成器与评估器（Generator-Evaluator）”双模型对抗机制，解决了 Agent 在长任务中“上下文焦虑”及对自己生成的代码过分乐观等系统性痛点。

**Anthropic 宣布取消软件工程师岗位的数据结构与算法（DSA）面试**
据 Pragmatic Engineer 报道，Anthropic 内部团队经过评估后发现，传统的数据结构与算法面试在评估现代软件工程师的实际能力上无法提供任何有效信号，因此决定彻底将其从招聘流程中移除。在 AI 原生与 vibe coding 普及的背景下，前沿 AI 实验室正在率先重塑软件工程的人力评估体系，从考察底层代码手写转向考察系统搭建与 Agent 驱动能力。

**Cognition 推出 Devin Oncall，在 SREGym 基准测试中实现 100% 缓解**
Cognition 正式发布自主运维智能体 Devin Oncall，旨在帮助团队全自动排查与缓解生产环境故障。Devin Oncall 在 SREGym 基准测试中实现了 100% 的端到端成功率与极短的响应缓解时间。随着 Devin Oncall 接入 Reducto、Rivian/VW 合作企业及 AngelList 等生产环境，AI 从单纯的代码编写（CodeGen）迈向自主接管运维（Self-driving Infrastructure）的趋势正加速落地。

### Anthropic Engineering Blog

* **Scaling Managed Agents: Decoupling the brain from the hands**
  * **核心论点**：Anthropic 解构了 Managed Agents 的底层架构，提出将模型的逻辑大脑、执行沙盒与持久化会话三者全面解耦，以支持长时运行的复杂 Agent。
  * **关键要点**：
    • 废弃将 Harness、沙盒和会话混合在单一容器的传统做法，避免“宠物式（Pets）”单点失效问题。
    • 将 Harness 和容器均作为“牲口（Cattle）”处理：容器崩溃时 Harness 捕获工具错误并重试；Harness 崩溃时可通过外部会话日志实时恢复。
    • 提出安全隔离原则：模型生成的未受信代码运行在沙盒内，而凭证（Git Auth、MCP OAuth）保存在外部 Vault 或代理层，沙盒无法接触敏感 Token。
    • 将会话日志（Session Log）作为独立于 Context Window 之外的持久化对象，使模型可以通过 `getEvents()` 进行灵活的切片阅读与历史回溯。
  * **值不值得深读**：非常值得深读，是构建工业级智能体架构与安全沙盒的必读指导范式。
  * 链接：https://www.anthropic.com/research/managed-agents

* **How we built Claude Code auto mode: a safer way to skip permissions**
  * **核心论点**：Claude Code 推出基于双层模型分类器的 Auto Mode（自动模式），在不丧失安全性的前提下免去频繁的人工审批点击。
  * **关键要点**：
    • 解决“审批疲劳（Approval Fatigue）”：用户在手动审批模式下会无脑通过 93% 的操作，失去防御效能。
    • 输入层防御：服务器端的 Prompt Injection 探针会在工具输出进入上下文前进行扫描，发现注入风险时植入警告。
    • 输出层分类器：基于 Sonnet 4.6 的分类器对危险指令进行评估，采用单 Token 快速过滤与 Chain-of-Thought（思维链）二次判定的双阶段机制。
    • 权限三分级：只读类工具直接放行；项目目录内的写文件直接放行；涉及 Shell、外网请求、跨目录操作等高风险行为触发分类器评估。
    • 重点拦截过度主动（Overeager）、误判影响范围（Honest Mistakes）以及数据外泄等无意危险行为。
  * **值不值得深读**：值得深读，对如何在 AI Agent 工具链中设计实用型模型安全护栏（Guardrails）提供了极佳的实践案例。
  * 链接：https://www.anthropic.com/research/claude-code-auto-mode

* **Harness design for long-running application development**
  * **核心论点**：Anthropic 提出一种包含“规划器-生成器-评估器（Planner-Generator-Evaluator）”的 3-Agent 架构，成功破解长时运行 Agent 在前端设计与复杂应用开发中的瓶颈。
  * **关键要点**：
    • 上下文重置（Context Resets）胜过单纯压缩：通过清空 Context Window 并通过结构化 Handoff 传递状态，彻底解决了模型的“上下文焦虑（Context Anxiety）”。
    • 解决自我评价盲目乐观问题：将评估职责单独解耦给外部 Evaluator，并为其配置详细的 Prompt 与 Playwright MCP 工具进行实际界面截图和交互。
    • 制定具体的量化设计指标：针对主观审美，拆解出设计质量（Design Quality）、原创性（Originality）、工艺（Craft）与功能性（Functionality）四大评分项。
    • 引入局部剪裁技术：在计算密集的重折叠/编译阶段，仅提取核心局部接口进行分析，将计算效率提升 8 倍以上。
  * **值不值得深读**：值得深读，非常适合正在开发全自动 Coding Agent 与复杂 Workflow 的架构师参考。
