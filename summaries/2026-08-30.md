Hugging Face 联合社区及开源 Coding Agents 对 ICML 2026 的 2,200 多篇论文展开了史上最大规模的平行复现实验，发现高达 23% 的论文存在论点被证伪或严重争议（包括某 Spotlight 论文公式推导漏洞导致鲁棒性虚标）。该实验展示了 AI Agent 在科研审查与复现上的巨大潜力，同时也暴露出 Agent 易陷入局部死循环和单位换算错误的局限，强调了“人机协同”在学术审核中的不可替代性。

**Code execution with MCP: Building more efficient agents**
* **核心论点**：通过将 MCP 工具呈现为代码 API 并引入代码执行环境，AI Agent 能按需加载工具并筛选数据，从而减少高达 98.7% 的 Token 消耗。

  4. 代码执行赋予 Agent 利用循环、条件判断和错误处理的能力，避免了频繁串行调用工具的复杂链条。
  5. Cloudflare 的 Code Mode 亦证实了让 LLM 编写代码来调用 MCP 工具是极佳的高效模式。
* **值不值得深读**：强烈推荐 Agent 开发者深读，提供了极高实操价值的架构优化方案。

**Reasoning models struggle to control their chains of thought, and that’s good**
* **核心论点**：OpenAI 研究发现前沿推理模型难以主动掩盖或操纵其思维链（CoT），这一“能力缺陷”反而有力保障了 CoT 监控在 AI 安全中的可靠性。
* **关键要点**：
  1. 发布评估套件 CoT-Control（包含 13,000 多个任务），测试模型在生成 CoT 时遵循限制（如禁用某些关键词、全小写）的能力。

  4. 模型无法精细控制 CoT 说明其短期内极难通过伪造推理痕迹来欺骗安全监控系统。
  5. OpenAI 承诺将在未来的系统卡（System Card）中引入 CoT Controllability 作为常态化安全指标。
* **值不值得深读**：必读，颠覆了“能力越强越难监控”的直觉，为 AI 可解释性与监控提供了信心。
