### Google Research Blog

#### The sleep framework: A new way for LLMs to retain knowledge in continual learning
* **核心论点**：受人类睡眠启发，Google 提出 Sleep 框架，使部署后的 LLM 能够在持续学习中避免灾难性遗忘。
* **关键要点**：
  * **双阶段机制**：分为“记忆巩固（NREM 慢波睡眠）”与“做梦（REM 睡眠）”两个阶段。

### Chain of Thought (Dan Shipper)

#### Agent-native Architectures: How to Build Apps After the End of Code
* **核心论点**：探讨代码撰写成本趋近于零之后，软件架构向“Agent 原生（Agent-native）”演进的新范式。
* **关键要点**：
  * 软件不再是预先写死逻辑的静态程序，而是围绕 Agent 推理循环构筑的动态适应系统。
* **值不值得深读**：短文 preview，可关注其后续长文。
* **原文链接**：https://every.to/chain-of-thought/agent-native-architectures-how-to-build-apps-after-the-end-of-code

#### Compound Engineering: How Every Codes With Agents
* **核心论点**：介绍 Every 团队在 100% Agent 编码时代总结的“复合工程（Compound Engineering）”工作流。
* **关键要点**：
  * **打破传统死循环**：传统工程中代码越多系统越复杂；复合工程通过建立 Agent 学习闭环，使每个新功能和 Bug 修复都转化为知识库，让后续开发越来越快。
  * **四步闭环**：Plan（规划）、Work（编写）、Review（审查）、Compound（沉淀）。
  * **精力分配**：80% 的工程精力放在 Plan 与 Review 环节，仅 20% 放在 Work 与 Compound 执行阶段。
  * 单个开发者借助 Claude Code 或 Factory Droid，能够轻松高效维护多个千万级用户产品。
* **值不值得深读**：强烈推荐，展现了现代化 Agent 驱动团队的生产力范式。
* **原文链接**：https://every.to/chain-of-thought/compound-engineering-how-every-codes-with-agents

### Argmin Gravitas (Ben Recht)

#### The Keynesian Subtweet
* **核心论点**：借由凯恩斯（Keynes）对不确定性的论述，批判机器学习与决策论中过度简化的期望效用最大化（Utility Maximization）。
* **关键要点**：
  * 真实世界中的重大不确定性（如战争、未来利率）无法像赌场轮盘那样计算出精确概率。
  * 决策模型中的概率与成本往往是人为编造的，过度依赖“理性的计算”反而会导致规避风险的恐惧与停滞。
* **值不值得深读**：推荐，对概率预测与 ML 决策假设深度反思的哲学好文。
* **原文链接**：https://www.argmin.net/p/the-keynesian-subtweet

#### You Should Always Go for It
* **核心论点**：讽刺体育分析（NFL 数据模型）将极其复杂的现场决策简化为看似精确的三位小数概率。
* **关键要点**：
  * 批判黑盒模型宣传的所谓“最佳策略”（如第四分降无脑选择“Go for it”），指责其忽略了现场战术执行与对抗的无限复杂性。
  * 呼吁决策分析应当保持透明度，而不是用计算模型的官僚主义剥夺竞技体育的乐趣。
* **值不值得深读**：有趣且犀利的杂文，适合轻松阅读。
* **原文链接**：https://www.argmin.net/p/you-should-always-go-for-it

### Paul Graham Essays

#### Writes and Write-Nots
* **核心论点**：Paul Graham 预测 AI 将导致社会剧烈分化为“会写作的人”与“完全不会写作的人”。
* **关键要点**：
  * 写作的本质是清晰思考，其过程本身极其艰难。
  * AI 充当了压力释放阀，导致中间层（写作水平普通的人）彻底消失。
  * 不写作意味着放弃了深度思考，未来社会将演变为“思考者（Thinks）”与“非思考者（Think-nots）”的分化。
* **值不值得深读**：强烈推荐，关于 AI 对人类思维影响的经典短论文。
* **原文链接**：https://paulgraham.com/writes.html

#### When To Do What You Love
* **核心论点**：剖析“追求热情”与“赚钱”之间的复杂边界与选择策略。
* **关键要点**：
  * 追求极度富有的最佳方式往往是从事自己最感兴趣的事，因为最具颠覆性的创业想法往往源于出于兴趣而做的项目（如 Apple、Google）。
  * 在面对不确定性时，应采取“保持在上游（Staying upwind）”策略，选择能够保留更多未来选项的方向（如优先选修数学而非经济学）。
* **值不值得深读**：推荐，充满人生智慧与职业规划思考的佳作。
* **原文链接**：https://paulgraham.com/when.html

#### Founder Mode
* **核心论点**：探讨创始人管理模式（Founder Mode）与职业经理人模式（Manager Mode）的根本区别。
* **关键要点**：
  * 传统商业教育教导的“雇佣优秀人才并放手让他们做”在创业公司扩展期往往会导致灾难。
  * 创始人模式打破了“仅通过直接下属沟通”的死板层级，倡导跨层级会议（Skip-level meetings）与对核心细节的绝对掌控（如 Steve Jobs 的 100 人精细管理）。
* **值不值得深读**：必读，硅谷近年来讨论度最高的管理学名篇。
* **原文链接**：https://paulgraham.com/foundermode.html
