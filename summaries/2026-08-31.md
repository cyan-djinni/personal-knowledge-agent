## 今日要点

**OpenAI 正式放弃 SWE-bench Verified 评测标杆**
OpenAI 发布研究报告指出，业内广泛使用的 SWE-bench Verified 存在严重新鲜度与污染问题，其审计的失败案例中有 59.4% 是由于测试用例过于苛刻或未说明需求导致的错误拒绝，且前沿 LLM 均已在训练集中接触过底层代码。这一决定意味着 AI 行业对 Agent 编程能力的评估正迈入“脱离污染基准”的新阶段，未来行业评测将全面转向 SWE-bench Pro 等未污染数据集，促使评估标准向真实复杂的工程场景回归。

**Anthropic 系统化提出 Context Engineering（上下文工程）实操框架**
随着 AI Agent 从单轮 Prompt 转向长时间跨度的自主推理，Anthropic 官方团队明确提出了从 Prompt Engineering 升级为 Context Engineering 的必然趋势。文章剖析了 Transformer 架构下 context rot（上下文腐化）与注意力预算有限的物理约束，提出了动态维护高信号 token 集合的实践原则。这一框架为开发者在多轮 Agent 循环中精简工具集、控制系统 Prompt 维度提供了最权威的技术指导。

**AI Agent 正在重塑企业软件工程基础设施**
来自 Coinbase、Faire 及 Anthropic 内部的实践表明，软件开发模式正经历从人类写代码到“Agent-first”的剧烈转变。Coinbase 内部 75% 的 PR 已由 Agent 自动创建，需求到上线时间缩短 90%；Anthropic 工程师使用 Fable 仅用 11 天即完成了 Bun 项目 50 万行代码向 Rust 的重构。传统的 Sprint 规划与行级 Code Review 正在失效，工程师角色的重心正快速转向意图定义、架构评估与 Agent 调度。

**OpenAI 推出 Private Safety Processing 与区块链防守标杆 EVMbench**
为解决企业在零数据保留（Zero Data Retention, ZDR）下无法评估跨多轮复杂 Agent 潜在安全风险的矛盾，OpenAI 预览了 Private Safety Processing 技术，允许在不接触客户明文内容的前提下利用加密信号识别违规行为。同时 OpenAI 联合 Paradigm 推出 EVMbench，专门评估 AI Agent 对智能合约漏洞的检测、补丁与利用能力，标志着前沿实验室正加速推动 AI 在区块链与高价值金融系统的防御性应用。

**Google Research 在表格 Foundation Model 与端侧加速上取得突破**
Google Research 引入了零样本表格基座模型 TabFM，通过 In-Context Learning（ICL）架构和数亿级合成数据训练，打破了长期由 XGBoost 等树状模型统治的结构化数据预测领域，免去了繁琐的特征工程。此外，Google 成功将 Multi-Token Prediction (MTP) 架构逆向集成至已冻结的端侧 Gemini Nano 模型中，在 Pixel 设备上实现了 50% 以上的推理速度提升和显著的功耗降低。

### Anthropic Engineering Blog

#### Effective context engineering for AI agents
* **核心论点**：应用 AI 开发的核心正在从 Prompt Engineering 演进为 Context Engineering，即在有限的注意力预算内精炼出最优的 token 组合。
* **关键要点**：
  • Context 特指 LLM 推理时包含的所有 token，包括系统指令、工具定义、MCP 数据与历史消息。
  • 解释了 Context Rot（上下文腐化）现象：随着 token 增加，Transformer 架构的 pairwise 关联（$n^2$ 复杂度）会被拉薄，检索精度下降。
  • System Prompt 应保持“黄金高度”：既避免硬编码脆弱逻辑，也避免过于泛化无指导意义。
  • 工具定义（Tools）应做到极简与职责单一；若工程师无法明确判断该调哪个工具，Agent 也必然失败。
  • 强调针对多轮 Agent 循环必须引入动态 Context 裁剪与提炼策略。
* **值不值得深读**：必读，AI Agent 开发者打造高性能架构的必读指南。
* 原文链接：https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents

#### Why we no longer evaluate SWE-bench Verified
* **核心论点**：OpenAI 宣布停止报告 SWE-bench Verified 评分，原因是该基准已严重污染且测试集存在大量内在缺陷。
* **关键要点**：
  • 审计发现 59.4% 模型常败的题目存在材料缺陷：35.5% 测试用例过于严格（要求特定未声明的函数名），18.8% 测试检查了未在描述中提出的额外功能。

  • OpenAI 推荐暂用 SWE-bench Pro 作为过渡，并呼吁行业建立无污染的新评估体系。

### Google Research Blog

#### Introducing TabFM: A zero-shot foundation model for tabular data
* **核心论点**：Google Research 发布 TabFM，将 In-Context Learning (ICL) 引入表格数据，实现无需训练与调参的零样本分类与回归。
* **关键要点**：

### Argmin Gravitas (Ben Recht)

#### Methods to Madness
* **核心论点**：借用功率举健身博主 Greg Nuckols 的著作，探讨如何用简化的控制论/适应性模型解释复杂的人体力量训练。
* **关键要点**：
  • 人体对运动刺激的反应符合稳态与适应模型（Fitness-Fatigue Model），属于典型的二次线性系统。
  • 强调渐进式超载（Progressive Overload）的核心原理简单明了，许多社交媒体网红试图通过伪科学复杂化。
  • 批评过于细碎的生物化学通路研究与微型 RCT，主张科学应专注于建立简单有用的预测模型与注重工程实操。
* **值不值得深读**：值得，适合对健身科学、控制论与科学方法论感兴趣的读者。
* 原文链接：https://www.argmin.net/p/methods-to-madness

#### Never Ending Math Equation
* **核心论点**：批判将教条式的“随机对照试验（RCT）”强行套用于物理治疗等复杂、主观且多阶段的医疗健康场景。
* **关键要点**：
  • 物理治疗是深度的多阶段决策树，无法像药物试验那样隔离单一干预变量或做到双盲。
  • 疼痛评估依赖 Numeric Ranking Scale 等主观指标，难以开展严格的数学与统计量化。
  • 呼吁超越狭隘的“循证”教条，重新重视工匠精神、临床实践与经验积累的价值。
* **值不值得深读**：值得，对科研方法论、医疗统计与复杂系统感兴趣者推荐。
* 原文链接：https://www.argmin.net/p/never-ending-math-equation

### South Park Commons

#### Trusting Your Agent Is Overrated
* **核心论点**：提出 AI Agent 信任度公式 $T = T_S / T_D$，指出解锁 Agent 采纳的关键在于降低“被要求的信任度（$T_D$）”。
* **关键要点**：
  • 信任供给（$T_S$）由凭证、直接证据与利益对齐构成；信任需求（$T_D$）由错误后果的风险杠杆（Stakes）与系统不透明度（Opacity）决定。
  • AI 时代 $T_S$ 信号变杂（证据易伪造，过程不可见），仅靠提高供给极其昂贵。
  • 降维打击的方法是削减分母 $T_D$：赋予操作 Undo 撤回机制、设计阶梯式授权、降低读写权限，并提供极度清晰的运行日志与假设复盘。
* **值不值得深读**：必读，AI Agent 产品经理与交互设计师必读的框架指南。
* 原文链接：https://blog.southparkcommons.com/p/trusting-your-agent-is-overrated

### Paul Graham Essays

#### Superlinear Returns
* **核心论点**：阐述现实世界中性能与回报非线性的客观规律，分析超线性回报（Superlinear Returns）的四大源头。
* **关键要点**：
  • 破除“付出多少得到多少”的线性迷思，商业与社会回报本质上是极度倾斜的。
  • 源头一：指数级增长（Exponential Growth），即当下的成就促进下一轮更大的增长（如知识积累、用户网络）。
  • 源头二：阈值与胜者通吃（Thresholds / Winner-Take-All），跨过临界点后将获得非对称收益。
  • 建议：始终选择具备复利增长属性的工作，保持对未知的过度好奇，不断学习。
* **值不值得深读**：必读，Paul Graham 经典思考文章，对人生规划与创业选择极具启发。
* 原文链接：https://paulgraham.com/superlinear.html

#### How to Do Great Work
* **核心论点**：汇总各领域做出杰出成就的共通方法论，提供了一份高度系统化的行动指南。
* **关键要点**：
  • 第一步：选择同时具备自然天赋与极高兴趣的领域（无需过于担心领域大小）。
  • 第二步：通过动手做自己的项目来快速探索；追随令人兴奋的好奇心。
  • 第三步：学足够多的知识以触及知识的前沿边界（Frontier），注意边界上被他人忽视的缝隙（Gaps）。
  • 第四步：大胆探索非主流的离群想法（Outlier Ideas），耐受长期的艰苦钻研。
* **值不值得深读**：必读，经典长文，适合反复阅读与实践对照。
* 原文链接：https://paulgraham.com/greatwork.html

#### How to Get New Ideas
* **核心论点**：指出获得新想法的关键在于敏锐地察觉知识前沿边缘的“异常与缝隙”。
* **关键要点**：
  • 知识呈现分形（Fractal）增长，靠近边缘就会发现大量未被解答的裂缝。
  • 对日常生活中显而易见却没人提问的现象保持敏锐的好奇。
* **值不值得深读**：短文，快速浏览精髓即可。
* 原文链接：https://paulgraham.com/getideas.html
