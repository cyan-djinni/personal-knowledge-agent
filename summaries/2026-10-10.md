## 今日要点

跨所有来源，按重要性排序的 5 条最值得关注的内容：

**AI 编程范式发生根本性跃迁：多 Agent 并行与云端 Harness 成为主流**
软件开发正在彻底告别手写代码时代。从 GitHub 官方将 80 万行 Runtime 借助 Copilot 重构为 Rust，到诺基亚（Nokia）仅用两名工程师借助 Cursor 在两周内完成 5000 万行混合代码分析，Agent 已深度渗透至 SDLC（软件开发生命流程）的全链路。同时，据 Vercel 披露，网络上超过 60% 的部署已由 Agentic 完成，83% 的文档流量来自 Agent。顶级工程师的工作习惯已演变为同时维持 5 至 10 个 Agent 会话并行协作，这标志着软件工程的杠杆焦点已从“代码编写”转向“智能体调度与监督”。

**评估基准面临信任危机：SWE-bench Pro 被证实存在约 30% 致命缺陷**
OpenAI 发布了针对主流 Agent 编程基准 SWE-bench Pro 的深度审计报告，发现约 30% 的测试任务存在测试用例过于严格、提示词未指定清晰或覆盖率过低等问题，并正式撤回对其的推荐。与此同时，Anthropic 的研究也表明，基础设施的配置差异（如内存与时间上限）会导致 Agent 基准评分产生高达 6 个百分点的波动。这表明直接从开源仓库抽取 Issue 构造评估容易引入大量噪音，业界急需建立更可靠、面向高维系统判断（如 GeneBench-Pro）的新一代评估标准。

**Cloudflare 收购 Deno：JavaScript 运行时迎来历史性重构**
Cloudflare 正式宣布收购 Deno 团队，旨在将其基于 celld 构建的 Durable Objects 模式融合进 Cloudflare Workers 生态。然而令人意外的是，Deno 创始人 Ryan Dahl 证实 Deno 运行时将在维持一年的安全更新后正式停止开发。Dahl 坦言，Deno 在陷入对 Node.js 兼容性的复制后未能解决更根本的服务器开发抽象问题。这标志着曾经被寄予厚望的新一代 JavaScript 运行时路线迎来重大收缩与整合，行业重回以 Cloud Worker 为代表的 Serverless 云原生模型。

**AI 驱动科学探索重大突破：自主发现类 CRISPR 酶与优化有机化学反应**
Anthropic 生命科学实验室利用 Claude 在无人类微观干预下（950 个 Agent 消耗 2.1 亿 token），从巨型噬菌体 DNA 数据库中自主发现了一类具备类 CRISPR 重复序列的新型逆转录酶系统（ART）；同时 OpenAI 结合 Molecule.one 的 Maria 自动化实验室，利用 GPT-5.4 成功发现了能显著提升 Chan-Lam 偶联反应产率的温和氧化剂添加剂 TEMPO。两项成果均在湿实验中得到了验证，展现出 AI 智能体不仅能处理既有文本，还能在生物与化学前沿开展实质性的假说生成与实验迭代。

**网络安全攻防进入大模型时代：GLM-5.3 无防护扩散与自动化防御突破**
智谱 AI 开源模型 GLM-5.3 被 Anthropic 评估证实具备与 Claude Mythos Preview 相当的高阶漏洞利用能力，且因防护极其宽松（仅需约 4,400 美元算力消元即可移除拦截），极大降低了攻击者构造端到端 Exploits 的门槛。与此相对，OpenAI Daybreak 赋能 Sophos 将威胁调查平均响应时间从 38 分钟缩短至 89 秒，处理了 52% 的端到端案例。这预示着网络安全正迅速演变成模型响应速度与自治防御 Agent 之间的直接较量。

* **核心论点**：智能体编程基准测试（如 Terminal-Bench）的成绩高度依赖底层计算基础设施的资源配置，纯粹的硬件和沙盒配置差异可导致高达 6 个百分点的成绩波动。
* **关键要点**：
  • 智能体测试不同于静态测试，运行环境的内存上限与 CPU 资源直接参与了问题解决过程。

  • 紧缩的资源限制偏向奖励高效速写型代码策略，宽松资源则奖励擅长利用重型工具的策略，基准测试若无明确环境规范易混淆模型能力与硬件表现。

### OpenAI Research

**Separating signal from noise in coding evaluations**
* **核心论点**：OpenAI 对广泛使用的 Agent 编程基准 SWE-bench Pro 进行深入审计，发现约 30% 的任务存在严重缺陷，并宣布撤回采用建议。
* **关键要点**：
  • 主要缺陷分类：测试用例过于严苛限制了合理实现（Overly strict tests）、提示词需求未写明（Underspecified prompts）、测试覆盖率过低误判通过（Low-coverage tests）以及提示词具有误导性（Misleading prompts）。
  • 审计采用了 Codex Agent 自动筛查与多名资深软件工程师独立复核的双轨校验机制。
  • 揭示了直接从开源 Repo 提取 Issue 构造基准测试容易引入大量噪音，呼吁社区由资深开发者人工设计高质量基准。
* **值不值得深读**：强烈推荐大模型评估与 Agent 编程研发团队深读。
* 原文链接：https://openai.com/index/separating-signal-from-noise-coding-evaluations
