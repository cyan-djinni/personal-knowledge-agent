# 每日摘要 2026-11-11

### 今日要点

**1. Google DeepMind 发布 Gemini 4 Carbon 与 AlphaProof Code 形式化验证突破**
Google 推出了新一代旗舰模型 Gemini 4 Carbon，不仅在 CursorBench 4.0 和网络安全漏洞检测上登顶，更结合全新 Agentic 框架 AlphaProof Code，首次成功对 Signal 加密协议的真实运行代码进行了数学级的形式化验证（Formal Verification），用 4 周时间完成了过去顶级专家团队需要耗时数年的工程，标志着 AI 驱动的绝对软件安全保障迈入实用化阶段。

**2. Anthropic 推出高级工具使用与 MCP 代码执行模式，Token 消耗最高降低 98.7%**
Anthropic 针对多工具 Agent 容易撑爆 Context Window 的痛点，推出了 Tool Search Tool（按需搜索工具）与 Programmatic Tool Calling（代码化工具调用）。Agent 不再需要将成百上千个工具的 JSON Schema 和中间结果全部塞入上下文，而是直接在沙盒中编写 Python 代码编排工具并过滤数据，在保障精度的同时将 token 开销暴降至多 98.7%。

**3. Google Research 提出 Sleep 框架，借鉴人类睡眠机制破解大模型灾难性遗忘**
为了解决大模型部署后知识静态截断与持续学习导致的“灾难性遗忘”难题，Google Research 提出了 Sleep 框架。模型通过交替进行慢波睡眠（将短期上下文提炼巩固至 MoE 参数中）与 REM 睡眠（生成自演进练习），实现了高达 10M token 的长上下文参数化内化，无需重新预训练即可持续吸收新知识并显著提升数学逻辑推理能力。

**4. Cursor Projects 升级为 Multiplayer 模式，打造首个团队与多 Agent 协同工作空间**
Cursor 打破了过去个人开发者独占 Agent 的孤岛状态，将 Projects 升级为多人协同（Multiplayer）。整个团队与各自运行的 Agent 能够共享统一的需求文档、架构图与决策记忆，共享 Task Board 实时展现人与 Agent 的协作动态，Agent 之间甚至能自动沟通接口变更与依赖顺序，提前规避代码合并冲突。

**5. AI 编程范式彻底转向“Compound Engineering”，工程师个人 PR 产出实现 11 倍暴涨**
根据 Pragmatic Engineer 最新大奖文章，在 AI-native 团队（如 Tano）中，工程师通过深度整合 Claude Code 等 Agent 工作流，每月合并 PR 量从传统模式下的 20 个暴增至 200+ 个。软件开发正从手写代码转向由“Plan-Work-Review-Compound”构成的复合工程（Compound Engineering），AI 对代码库的认知随项目规模同步增长，单人即可轻松维系多个复杂生产级系统。

    - 支持状态持久化与技能（Skills）沉淀，Agent 可以将编写成功的代码保存为可复用函数。
