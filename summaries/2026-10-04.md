**How we contain Claude across products**
• **核心论点**：Anthropic 详细拆解了其在 claude.ai、Claude Code 及 Claude Cowork 等产品中限制 Agent 潜在危害范围（Blast radius）的工程架构。

  • 防御体系须在运行环境、模型训练与外部 Connector 访问权限三层做到深度叠置。
• **值不值得深读**：强烈推荐深读，是构建安全 Agent 运行环境不可多得的系统级架构指南。

**Scaling Managed Agents: Decoupling the brain from the hands**
• **核心论点**：Anthropic 推出 Managed Agents 托管服务，通过将 Agent 的“大脑”（模型与 Harness）与“双手”（沙箱及工具）解耦，实现了长程任务的高可用与可扩展性。
• **关键要点**：
  • 早期将 Harness 与沙箱耦合在单一容器内导致“宠物式”运维，无法有效 Debug 且易丢失 Session 状态。
  • 解耦后，Harness 将沙箱视为独立 API 调用，发生故障时可随时重新初始化容器，实现无状态漂移。
  • 敏感凭据（如 Git Token、OAuth）完全存储于沙箱外的 Secure Vault，Agent 仅通过代理调用，无法直接接触密钥。
  • 将完整的 Session Log 储存于外部上下文对象中，支持灵活截取与回溯，解决了上下文压缩导致的不可逆信息丢失。
• **值不值得深读**：非常值得深读，是生产环境大规模部署生产力 Agent 的标杆架构设计。
