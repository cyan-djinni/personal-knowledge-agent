# 每日摘要 2026-11-06

### 今日要点

**AI 攻防与开源漏洞挖掘进入“模型原生理”时代**
Anthropic 推出面向开源社区的免人工审查漏洞扫描服务 OSS Scanner（基于 Claude Mythos），OpenAI 亦发布了专用的网络安全模型 GPT-6 Cyber。大模型正从辅助写代码转向自主进行大规模软件漏洞挖掘与补丁生成，在 PostgreSQL、OpenSSL 和 curl 等核心项目中均已定位到致命漏洞，网络安全防线正在发生根本性转移。

**底层硬件与大模型内核协同重构**
Cursor 宣布开源 Mixture-of-Kittens (MoK)，这是一个专门针对 NVIDIA GB300 NVL72 架构打造的 MoE 训练 Megakernel。通过在拉取模式（Pull-based）下将通信与计算融合进单一内核，并引入环形令牌缓冲区消除了 CPU-GPU 同步，实现了 1.41 倍的端到端吞吐提升，展示了前沿 AI 编程公司主动向下重构硬件算力瓶颈的技术趋势。

**AI 编程范式彻底颠覆与招聘标准重塑**
根据 Pragmatic Engineer 的最新行业报告，GitHub 上 Agent 自动生成的 PR 数量在 8 个月内激增 9 倍，单月提交量已彻底压倒人类开发者；同时 Anthropic 招聘负责人宣布彻底废除传统 Coding 面试，强调“业务影响力和饥饿感远胜于写代码资历”，标志着软件工程师核心价值的重组。

**生物学与连接组学（Connectomics）的历史性突破**
Google 与 Janelia 团队在《Cell》发表重磅成果，绘制出包含 16.6 万个神经元和 1.25 亿突触的雄果蝇完整大脑及中央神经系统图谱。这是迄今最大规模的完整神经网络映射，配合 AI 重构与跨性别对比，为解析复杂行为回路与脑疾病治疗迈出关键一步。

**前沿大模型安全治理与使用规范演进**
Anthropic 更新了 2026 版 Usage Policy，合并欺诈防范规则、禁止武器控制软件与无同意追踪，并首次赋予 Claude 在面对持续虐待时挂断对话的权限。这表明随着 Agent 具备自主物理与系统操作能力，AI 厂商正在建立更严苛、具体的行为红线与人机回路（Human-in-the-loop）控制机制。
