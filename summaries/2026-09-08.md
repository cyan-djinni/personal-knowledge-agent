# 今日要点

**Anthropic 发布 Claude Opus 5 刷新行业 SOTA 记录**
Anthropic 正式推出 Claude Opus 5 模型，在编码（Frontier-Bench）和复杂知识工作（GDPval-AA、ARC-AGI 3）评估中成为新的行业标杆，且价格仅为 Fable 5 的一半。Opus 5 具备极强的自主纠错与验证能力，能自动编写计算机视觉流水线重建 3D 模型，并精准定位和修复开源项目的边缘 Bug，标志着高阶前沿智能全面步入日常开发的标准配置。

**OpenAI 宣布终止向 Cursor 提供模型服务**
因 SpaceX 收购 Cursor 触发了合同变更条款，OpenAI 决定在 2026 年 11 月 12 日正式终止向 Cursor 供应 OpenAI 模型。OpenAI 表示，在埃隆·马斯克旗下的其他公司（如 xAI）此前多次违反服务条款的背景下，无法确保 SpaceX 运营下的 Cursor 能够合规使用其模型，这一决定引发了开发者生态和编程工具领域的重大震动。

**Google DeepMind 推出 Gemini 3.6 Flash 及 Gemini Robotics 2 具身智能**
Google DeepMind 密集发布多项重大更新，包括效率与表现大幅提升的 Gemini 3.6 Flash、超低延迟的 3.5 Flash-Lite，以及面向安全的 3.5 Flash Cyber 模型。同时推出的 Gemini Robotics 2 套件使机器人具备全套全身协调控制、双手精细操纵（如打结、封口）以及多机器人协同工作能力，加速推动具身 AGI 的落地。

**OpenAI 开源 IH-Challenge 提升对抗 Prompt Injection 能力并探讨 CoT 监控**
OpenAI 发布了全新的强化学习训练数据集 IH-Challenge 并推出 GPT-5 Mini-R，通过严格确立系统消息大于开发者、用户及工具的指令层级（System > developer > user > tool），大幅增强了模型抵抗提示词注入和安全定向的能力。此外，研究还证实当前推理模型难以主动操纵思维链（CoT），这使得 CoT 监控在安全监督中保持了极高的可靠性。

**智能体外壳（Agent Harness）演进：从代码硬编码走向环境自愈**
来自 Latent Space 与 Cursor 的深度技术剖析显示，Agent Harness（智能体运行环境）正经历从“外挂式 Prompt”向“自愈型环境与权限管理”的范式转变。随着 LLM 逐渐将上下文压缩、工具选择等功能内化至模型权重，现代 Harness 正在大幅精简硬编码，转而聚焦于提供安全沙盒、环境自愈（Cloud Doctor）以及人机注意力接管机制。

### Anthropic Engineering Blog

#### Code execution with MCP: Building more efficient agents
* **核心论点**：通过将 Model Context Protocol (MCP) 工具转化为代码 API 并配合代码执行环境，可将 Agent 的 Token 消耗降低多达 98.7%。
* **关键要点**：
  • 传统 MCP 加载方式将数千个工具定义直接注入 Context Window，导致推理速度变慢且成本高昂。
  • 传统直接工具调用会导致中间数据（如大型会议文本）多次在上下文和模型间搬运，造成严重的上下文污染。
  • 新方案将 MCP 服务器呈现为文件系统上的代码 API，Agent 按需检索工具定义（Code Mode）。
  • 数据处理前置：Agent 可在代码执行环境中直接完成 10,000 行电子表格过滤或数据聚合，仅将最终结果返回给上下文。
  • 逻辑封装：复杂循环、条件判断和错误处理直接由代码执行，取代多次单步工具调用的链式耗损。
* **值不值得深读**：非常值得深读，这是优化 Agent 成本、 Latency 以及解决 Token 膨胀的关键工程实践。
原文链接：https://www.anthropic.com/engineering/code-execution-with-mcp

#### Beyond permission prompts: making Claude Code more secure and autonomous
* **核心论点**：Claude Code 引入操作系统级沙盒（Sandboxing）与 Web 端沙盒环境，在大幅提升安全性的同时减少了 84% 的用户权限确认弹窗。
* **关键要点**：
  • 传统基于权限的读写确认会导致用户“批准疲劳”，反而降低了安全性。

  • 开源了沙盒运行时研究预览版，可用于任意 Agent、进程和 MCP 服务器的安全隔离。
  • 推出网页版 Claude Code，在云端完全隔离的沙盒中运行，敏感凭证（如 Git 凭证、签名密钥）通过定制代理服务处理，绝不暴露给 Agent。
* **值不值得深读**：推荐深读，对研发 AI 编程 Agent 的安全防护与权限架构设计有重大指导意义。

#### Equipping agents for the real world with Agent Skills
* **核心论点**：Anthropic 提出 Agent Skills 开放标准，通过渐进式披露（Progressive Disclosure）的文件结构让通用 Agent 快速掌握特定领域的专业能力。
* **关键要点**：
  • Skill 是一个包含 `SKILL.md` 的文件夹，通过 YAML 元数据在启动时加载名称和描述。

  • 已经全面支持 Claude.ai、Claude Code、Claude Agent SDK 及开发者平台。

#### Reasoning models struggle to control their chains of thought, and that’s good
* **核心论点**：研究表明当前的推理模型难以主动操纵或隐藏其思维链（Chain of Thought），这一能力缺陷显著保障了 CoT 安全监控的可信度。
* **关键要点**：
  • 推出包含超 13,000 个任务的 CoT-Control 开源评估集，测试模型遵循内在思维链约束的能力。
  • 评估的 13 个前沿模型得分普遍极低（最高不超过 15.4%），即模型即使在 CoT 中意识到违反了指令，也无法有效纠正自己的思维过程。
  • 延长思考时间（Test-time compute）和增加强化学习训练会进一步降低模型对思维链的掌控力。
  • OpenAI 宣布将在 GPT-5.4 Thinking 等后续系统的 System Card 中同步报告 CoT controllability 指标。
* **值不值得深读**：推荐深读，反直觉地解释了模型“缺点”如何成为 AI Safety 的天然屏障。
原文链接：https://openai.com/index/reasoning-models-chain-of-thought-controllability
