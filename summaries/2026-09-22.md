**Anthropic 工程师展示多 Agent 协作极限：16 个 Claude 实例成功自主编写 C 编译器**
Nicholas Carlini 详细展示了利用“Agent Teams”架构进行长程自主编程的突破性实验。他部署了 16 个 Claude 实例在 Docker 和 Git 环境中并行协作，在无人类实时干预的情况下，消耗了近 2,000 个 Claude Code 会话和 20,000 美元 API 费用，最终产出了包含 10 万行 Rust 代码的 C 编译器，成功编译了 x86、ARM 和 RISC-V 架构下的 Linux 6.9 内核。该实验证明了通过精密的测试套件设计、确定性反馈循环和差异化验证机制（如引入 GCC 作为真值 Oracle），AI Agent 可以跨越复杂软件工程的临界点，实现超大规模的自主代码构建。
链接：https://www.anthropic.com/engineering/building-c-compiler

**TypeSafe AI 发布 Jev：颠覆生成式 AI 范式的“System One 决策模型”**
由前 OpenAI Post-training 团队成员 Diogo Almeida 创立的 TypeSafe AI 推出了全新模型 Jev，引入了“决策模型（Decision Model）”范式。不同于传统 LLM 输出自回归文本 token，Jev 接收非结构化输入后直接输出类型化的概率决策和浮点数评分，且输出完全免费，输入成本极低（每百万 token $0.042）。其核心技术在于“校验决策强化学习（RLCD）”，专为精准、高速、低成本的系统级编程决策而生，正在掀起自动化与 Agent 架构的新一轮变革。
链接：https://simonwillison.net/2026/Sep/21/jev/

**OpenAI 内部模型破解百余项数学难题，联合成立独立数学咨询小组并倡导 RSI 规范**
OpenAI 宣布其内部训练的新模型成功解决了包括纳维-斯托克斯（Navier-Stokes）千禧年大奖难题在内的 100 多项长期未决的数学难题。为应对 AI 在基础科学领域的爆发式突破及其带来的学术冲击，OpenAI 协助普林斯顿高等研究院（IAS）等机构设立了独立的数学与 AI 咨询小组。同时，OpenAI 发文呼吁制定递归自我提升（Recursive Self-Improvement, RSI）的国际安全标准，防止完全自主迭代的 AI 失去人类控制。
链接：https://openai.com/index/advisory-group-on-mathematics-and-ai

**核心论点**：Paul Graham 探讨人生的核心原则：照顾他人与世界，并致力于创造优秀的新事物（Make good new things）。
**值不值得深读**：PG 经典随笔，强烈推荐阅读。
链接：https://paulgraham.com/do.html

• **The Origins of Wokeness**
**核心论点**：剖析 Wokeness 与政治正确历史演变，论述其作为一种表象化道德纯洁性（Priggishness）的社会心理学根源。
**值不值得深读**：PG 极具争议性的文化评论，感兴趣可读。
链接：https://paulgraham.com/woke.html

• **Writes and Write-Nots**
**核心论点**：警告 AI 普及将导致世界分裂为“会写作的人”与“不会写作的人”，而写作即思考，最终演变成思维能力的贫富分化。
**值不值得深读**：经典名篇，强力推荐阅读。
链接：https://paulgraham.com/writes.html
