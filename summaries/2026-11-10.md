## 今日要点

**Anthropic 发布新一代旗舰模型 Claude Fable 5.2 与 Mythos 5.2**
Anthropic 正式推出了升级版旗舰模型 Claude Fable 5.2 与安全强化版 Claude Mythos 5.2。新模型在编程、复杂推理与视觉理解上取得重大突破，不仅生成速度提升 30%、API 价格下调 20%，还在 30 小时内自主完成了费马大定理的形式化证明，并在理论物理的黑洞研究中解决了两个长期未决的问题。它的发布重新夺回了全球大模型排行榜榜首，也为其正在开展的华尔街 IPO 路演打下了坚实基础。

**Google DeepMind 推出 Gemini 4 Argon 与轻量级 EmbeddingGemma 2**
Google 宣布推出针对长流程深度推理与网络安全防御的旗舰模型 Gemini 4 Argon，拥有高达 100 万 token 的超长输出上限，在真实代码库迁移（如将 80 万行 C/C++ 迁移至 Rust）与漏洞补丁构建上表现优异。同时，Google 还开源了 7.4 亿参数的本地多模态嵌入模型 EmbeddingGemma 2，统一了文本、代码、图像、视频与音频的向量空间，为边缘设备上的隐私级 RAG 系统落地提供了强大支持。

**开发工具生态演进：从 Agent SDK 到云端沙盒自动化**
AI 软件工程工具链正全面从单纯的聊天窗口向高度集成的软件工厂演进。Cursor 推出 Agent SDK 与 Self-Hosted Machines 架构，支持企业在自有网络中弹性运行并行代码 Agent；Devin 推出 Devin Security 2.0，接入前沿网络安全大模型实现自动化漏洞扫描与修复 PR 生成；GitHub Copilot 则引入 Canvas 交互与 VS Code 协同。这些动态表明，利用云端沙盒与多 Agent 协同来自动承接复杂工程任务已成为行业标配。

**密码学与可证实推理（Provable Inference）取得重大突破**
Anthropic 研发团队发布了开源可证实推理系统 FlashProve，利用零知识证明（zkSNARK）解决了用户无法验证大模型响应真实来源与权重的行业痛点。在单个 H100 GPU 上，FlashProve 对 4000 亿参数的 Llama 4 Maverick 模型实施证明生成的速度达到了 110 tokens/秒。这一突破不仅增强了用户对模型调用的信任，也为未来的 AI 发展步调监管与合规审计提供了可行可行技术路径。

**前沿实验室数据采购范式转移：百亿美元级专家 RL 环境**
根据 Latent Space 与 Handshake AI 团队的深度研讨，前沿 AI 实验室的数据采购正从早期的低成本文本标注转向由顶级专业人士打造的深度强化学习（RL）仿真环境。在金融分析、生命科学及安全对齐等高阶领域，简单的合成数据极易引发模型的“奖励机制作弊”（Reward Hacking），目前行业正倾力投入构建高度逼真的动态沙盒与复杂评分规则，以支撑大模型在真实长流程决策中的可靠落地。

  • 结合 Gemma 4 生成模型，可构建完全离线的端侧多模态 RAG 系统。
