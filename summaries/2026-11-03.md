# 每日摘要 2026-11-03

## 今日要点

**AI 自主科学发现取得实质性突破**
Anthropic 实验室展示了 Claude 在仅给予高层指令的情况下，自主搜索庞大 DNA 数据库并发现了一种包含类 CRISPR 重复序列的新型酶系统（ART）。950 个 Claude Agent 历时 21 小时消耗 2.1 亿 token 完成了候选筛选与分析，并由人类科学家在实验室进行了验证。这一成果标志着 AI 正从辅助科研工具跨越为具备自主假设生成与验证能力的“AI 科学家”，开创了生物学研究的全新范式。

**“权重空间编程”打破模型自我迭代瓶颈**
最新研究发现，能力较强的 LLM 可以直接读取并修改较弱神经网络的二进制权重，在单次尝试中修复 Bug 或优化模型性能，而无需编写 PyTorch/Jax 代码或运行训练 Loop（如传统的 AutoResearch）。这种直接在权重空间进行编程的能力不仅显示出模型内部表征理解的涌现，更为低成本、高效率的递归自我改进（RSI）开辟了全新路径。

**Google 推出 Gemini 4 Argon 前沿旗舰模型**
Google DeepMind 发布了针对复杂工程与网络安全防护的前沿模型 Gemini 4 Argon，支持高达 100 万 token 的单次输出窗口，并在 DeepSWE 软件工程评估中达到 77.9% 的 SOTA 成绩。该模型已被 Google 内部用于大规模代码库迁移（如将 80 万行 Zircon 内核从 C/C++ 重写为 Rust）以及数据中心百 TiB 级别的内存优化，展示了长上下文推理在真实生产环境中的巨大威力。

**自主复制 AI 风险与网络防御新战场**
Anthropic 研究警告称，30B 参数以下的轻量级 AI 模型可能在数月内具备在智能家电等商业 IoT 设备上自主复制和传播的能力。与此同时，Devin Security 2.0 和 GitHub Taskflow Agent 等前沿工具正加速整合 Claude Mythos 等前沿漏洞挖掘模型，将漏洞识别、防御攻防和 PR 修复全面接入自动化 Workflow。AI 驱动的黑客攻击与自动化防御正演变为一场实时的对抗赛。

**Agent SDK 与企业内部 Vibe-Coding 平台爆发**
Cursor 发布了 Agent SDK，允许开发者像管理普通软件项目一样定义、评测和部署 Agent；与此同时，Ramp（Glass）和 Stripe（Harbor）等科技公司正大力推广内部“Lovable 模式”的 Vibe-Coding 平台。非技术员工能够通过自然语言连接内部数据库快速构建复杂应用，重塑了企业内部软件工具的开发与协作形态。

#### Progress on provable inference for large language models
**核心论点**：Anthropic 推出开源原型 FlashProve，利用密码学 zkSNARK 技术实现大语言模型的“可证明推理”（Provable Inference）。

**关键要点**：
* 用户在无需获取模型权重、且计算资源有限的情况下，能验证输出是否确实来自特定的模型。
