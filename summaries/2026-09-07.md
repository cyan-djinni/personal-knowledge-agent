### 今日要点

**Google DeepMind 在《Nature》发表 WeatherNext，开源气象预测大模型**
Google DeepMind 开源了 WeatherNext 2 及 WeatherNext Cyclones 模型权重与代码，其在热带气旋路径、强度及风暴结构的预测精度上相比传统物理模型整整提前了一天（相当于气象学十年的进步）。该模型通过结合全球大气动力学与历史气旋数据，能在 TPU 上一分钟内生成 1,000 个系综预测样本，精准捕捉突发增强等尾部风险，标志着 AI 在连续物理系统模拟与科学计算（AI for Science）领域取得了历史性突破。

**SpaceX 收购 Cursor 后引发商业切割，OpenAI 彻底切断 API 供应**

**Demystifying evals for AI agents**
* **核心论点**：系统阐述了针对多轮交互、状态变更的 AI Agent 进行自动化评估（Evals）的设计原则、方法论与工程实践。
* **关键要点**：
  * Agent 的多轮工具调用与自适应特性导致错误容易累积，且前沿模型常能找到打破静态规则的创新解法，使评估难度远高于单轮 LLM。
  * 评估架构应结合基于代码（确定性）、基于模型（LLM Judge）和人工评价三种评分机制，并明确区分能力评估（Capability）与回归测试（Regression）。
  * 能力评估旨在测量 Agent 能做什么，初始通过率应较低；回归测试旨在防范退化，通过率应接近 100%。
  * 对代码 Agent，SWE-bench 和 Terminal-Bench 等确定性测试环境能通过单元测试高效测量效果。
  * 早期建立 Evals 能帮助团队明确成功标准，并在新模型发布时快速验证与切换，避免在生产环境中盲目调试。

**Effective harnesses for long-running agents**
* **核心论点**：提出了由初始化 Agent（Initializer）与编码 Agent 配合的双层 Scaffolding 方案，解决 Agent 在跨多个上下文窗口运行复杂长任务时的记忆失真与中断问题。
* **关键要点**：
  * 长行程 Agent 的核心瓶颈在于跨上下文窗口启动时缺乏历史记忆，传统上下文压缩（Compaction）无法完美传递清晰指令。

  * 强制要求 Agent 使用 Puppeteer 等浏览器自动化工具进行端到端人类视角的真实测试，防止其在代码未实际跑通时即标记完成。
  * 保持环境“干净状态”（Clean state）能极大减少下一个 Agent 猜测和恢复环境的时间成本。

“I wouldn't say superintelligence is bad. I would say it's dangerous. It seems pretty likely that you end up with AI takeover as a result of building superintelligence.”
