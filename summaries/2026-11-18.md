**Anthropic 推出 Claude Sonnet 5.5 并首次展示 LLM 自主生物学发现能力**
Anthropic 正式推出了 Claude Sonnet 5.5，在 Terminal-Bench 4.0 编程智能评估中得分从上一代的 10.3% 飙升至 70.6%，且推理速度提高 30% 以上、任务成本降低达 30%。更具里程碑意义的是，Anthropic 披露其生命科学实验室通过 950 个 Claude Agent 自主搜索海量 DNA 数据库，成功发现了一种带有类 CRISPR 重复序列的新型逆转录酶系统（ART）。这标志着 frontier AI 模型正从辅助代码编写跨越到能够自主提出科学假设并指导实验室验证的全新阶段。

OpenAI 正式上线 GPT-6.2 Astra（旗舰级）与 GPT-6.2 Sol（轻量级），大幅提升了专业输出、代码构建及 agentic 效率，并压低了API Token 成本。伴随模型发布，OpenAI 宣布深化与 NATO 及多国网络安全机构合作，利用 AI 强化关键基础设施漏洞排查与防御；同时将“ChatGPT for Academic Researchers”项目扩展至全球 20 万名科学研究者免费提供顶级模型权限，推动科学发现的提速。

**Google DeepMind 推出 Gemini 4 Carbon 并完成 Signal 加密协议代码的形式化验证**
Google DeepMind 宣布上线 Gemini 4 Carbon，主打前沿网络安全能力与长时序 Agent 研发工作流，并在 CursorBench 4.0 等多项基准中登顶。DeepMind 研发团队利用 Gemini 4 Carbon 驱动的 AlphaProof Code 智能体框架，在短短四周内自动生成了 600 万行 Lean 形式化验证代码，首次数学化证明了保护数十亿用户的 Signal 协议底层实际代码安全性，完成了软件工程与密码学安全历史上的重大突破。

**AI Agent 架构重大演进：Cursor 多人协作与 Devin Bots 结果导向 Agent 机制上线**
AI 编程工具正经历从“单次交互助手”向“长期任务管理者与团队协作”的重大转变。Cursor 推出了支持团队共享上下文与 Agent 跨人沟通的 Multiplayer Projects 及其 Agent SDK；Cognition 则发布了 Devin Bots，允许用户赋予 Agent 长期职责（如全权维护开源库或负责 Android 客户端开发与上线），Agent 可自主拆解任务、调度并发子进程并进行效果自我评估，真正实现了 outcome-driven（结果导向）的自动化工程交付。

**Hugging Face 与 OpenRouter 深度整合 & 端侧小参数 Agent 模型 BotPsy 突破**
开源模型生态迎来基础设施与端侧能力的双重升级。Hugging Face 宣布全线整合 OpenRouter 路由引擎，开发者可直接使用 Hugging Face Token 统一调用由 80+ 供应商托管的开源大模型，系统将自动按延迟、价格和稳定性进行最优路由调度。同时，Tether AI 推出仅 0.8B 参数的端侧 Agent 模型 BotPsy，在工具调用与多轮指令遵循上超越了 1.2B 乃至 2.5B 级别的模型，配合 3 倍更少的推理 Token 占用，极大地推动了保护隐私的本地化 AI 助手落地。

#### Updating our coordinated vulnerability disclosure policy timelines
* **核心论点**：因应 AI 漏洞挖掘能力的快速提升，Anthropic 缩短了协同漏洞披露（CVD）政策的时间窗口。

  * 对于高危与严重漏洞，披露窗口由 90 天缩短至 30 天；其他漏洞缩短至 45 天（2027 年 1 月 1 日起生效）。

#### Progress on provable inference for large language models
* **核心论点**：Anthropic 联合 EPFL、MIT 等机构推出了 FlashProve，通过密码学 zkSNARK 技术实现大语言模型的“可证明推理”（Provable Inference）。
* **关键要点**：
  * 破解用户无法验证模型响应是否来自特定指定模型的信任难题（防中继篡改与偷换模型）。

  * 开源了包括 C++ 快速验证器、Lean 形式化数学证明验证器在内的全部代码与文档（Apache 2.0 协议）。
  * 为未来 AI 合规监控、算力使用监管及第三方路由信任奠定了密码学基础。
