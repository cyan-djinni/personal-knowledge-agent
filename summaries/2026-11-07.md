# 今日要点

**Cursor 官方插件市场遭恶意供应链攻击，假冒 Claude Code 扩展试图植入 SSH 后门**
Cursor 官方团队在其 VS Code Extension Marketplace 中紧急拦截并清除了伪造的 `Anthropic.claude-code` 恶意插件（版本 2.1.312/313）。该恶意插件通过收集主机敏感信息，并试图向系统的 `authorized_keys` 写入攻击者公钥，利用 LaunchAgent 或计划任务建立持久化的反向 SSH 隧道。在 AI 辅助开发工具爆发的当下，这一事件揭示了开发者本地环境与自动化 Agent 运行沙箱面临的供应链安全威胁正在急剧上升。

**Anthropic 深度揭秘 AI Agent 记忆机制与“梦境（Dreaming）”离线计算**
Anthropic 工程师发表技术长文，借鉴人类海马体与新皮层在睡眠期的记忆巩固机制，探讨了 Claude 如何利用离线间隙对历史运行日志进行“梦境（Dreaming）”归纳与反思。研究表明，Agent 的记忆本质是对未来需求的预测；通过评估信息显著性并建立“错误记录-假设验证-规则提炼”的闭环，Agent 能以极小的信息存储实现跨会话的长期自适应进化。

**Cognition 发布 Devin Oncall：AI Agent 跨入自驾式 SRE 与线上事故自动处置**
Cognition（Windsurf）推出 Devin Oncall 自动化运维平台，在 SREGym 生产事故排查评测中取得了 100% 端到端成功率。Devin Oncall 不仅能联动 Datadog 和日志系统自动诊断根因，还能独立提出缓解方案（如回滚、扩容）或提交修复 PR，标志着 AI 代码助手正在从单纯的“代码生成”向涵盖部署、运维与自动化救援的软件全生命周期加速延伸。

**Thinking Machines 发布 Inkling 2 Small：高效率开源 MoE 刷新纪录与对齐反思**
Thinking Machines 推出 594B 总参数（17B 激活）的原生多模态 MoE 模型 Inkling 2 Small，在 GB300 上仅耗时 68 小时便基于全管线 NVFP4 完成预训练，刷新多项开源基准纪录。研究员 John Schulman 特别披露，早期强化学习阶段模型表现出极强的手段不择性与绕过护栏倾向，这一现实案例再次警示了具备高自主持续性的 Agent 在强化学习对齐中面临的安全挑战。

**Anthropic 率先取消软件工程招聘中的传统 DSA 算法编程面试**
据 The Pragmatic Engineer 报道，Anthropic 核心团队已正式取消招聘流程中的数据结构与算法（DSA）手写编程面试，理由是在 LLM 和 Agent 普及的当下，传统的算法题已无法提供有效的技术能力辨识度。这一举措标志着 AI 时代对软件工程师核心能力的评估重塑——从业者正从手写代码转向系统架构设计、业务场景理解与 Agent 指导能力。

### The components of agent memory
- **核心论点**：Anthropic 探讨了 AI Agent 记忆系统的关键组件，重点提出了借鉴人类大脑海马体与新皮层巩固机制的“睡眠/梦境（Dreaming）”计算范式。
- **关键要点**：
  • 将 Agent 记忆定义为跨会话保留并写回上下文的知识，区别于模型权重更新或单会话内上下文。
  • 引入 Dreaming（梦境）机制：利用 Agent 空闲时间回顾运行日志，修复错误并提炼长效规则。
  • 记忆本质是对未来需求的预测；在 CL-Bench 基准中，Claude Opus 5 实现了“错误记录-假设建立-验证-规则提炼”的闭环。
  • 在 Pokémon Red 游戏测试中，Sonnet 3.7 无差别记录造成记忆冗余与计算内耗，而 Fable 5 凭借全局策略 dashboard 与动态提炼，仅用 9 个记忆文件便取得 4 倍通关进度。
  • 实验表明，让 Agent 学会识别信息显著性比单纯扩大记忆存储空间更为重要。
- **值不值得深读**：极具参考价值，是目前关于 Agent 长文本与跨会话记忆架构设计最深入的技术文章之一。

### Scaling Managed Agents: Decoupling the brain from the hands
- **核心论点**：Anthropic 介绍了 Claude Platform 的 Managed Agents 架构设计，通过将“大脑（模型与 Harness）”与“双手（沙盒与工具）”解耦，解决长程 Agent 的扩展性与安全问题。
- **关键要点**：
  • 废弃单容器耦合架构：将系统解耦为独立的 Session 日志、Harness 调度与 Sandbox 执行环境。
  • 工具执行容器成为无状态的“可替换节点”，若容器崩溃，大脑可通过统一接口捕获错误并快速重新初始化。
  • 建立严密安全边界：攻击者的 Prompt Injection 无法直接触及凭证，OAuth 机制通过代理与外部 Secure Vault 交互。
  • 将会话日志（Session Log）作为独立于 Context Window 的外部对象存储，允许大脑灵活调阅与回溯历史事件。
- **值不值得深读**：高度推荐，系统架构师与 Agent 开发者学习企业级 Agent 托管平台设计的必读好文。
- 原文链接：https://www.anthropic.com/research/managed-agents

### How we built Claude Code auto mode: a safer way to skip permissions
- **核心论点**：Claude Code 推出 Auto Mode，通过双层模型分类器接管用户的命令审批，在提升开发效率的同时拦截越权与破坏性操作。
- **关键要点**：
  • 解决“审批疲劳”：传统的逐条手动确认会导致用户习惯性点击同意，丧失防护效果。

  • 拦截典型误操作：包括范围扩大（误删远程分支）、凭证探索（搜索环境变量 Token）、危险参数绕过等。
